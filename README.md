# Parque de gatitos

Escena animada en pixel art: un parque con arcoíris, flores y mariposas donde muchos gatitos de distintos pelajes y contexturas pasean, se persiguen, juegan, ruedan, se lamen, duermen, se meten en una caja, trepan un gimnasio gatuno y se tiran por el tobogán.

Verla en línea: https://mfbalestra.github.io/parque-de-gatitos/

La página muestra solo la escena, a pantalla completa. Tocá el pasto para tirar un ovillo: los gatitos más cercanos corren a buscarlo.

## Cómo está hecho

Es una sola página, `index.html`, sin dependencias: todo se dibuja píxel a píxel en un `canvas`. Para verla localmente alcanza con abrir el archivo en el navegador.
